# 晶塔世界卡牌实现准备

来源：晶塔世界角色.docx 与用户补充规则。当前为阅读与规格整理，尚未编写或编译模组代码。遗物和药水暂不纳入。

## 已确认的基础规则

- **延拓**：每获得1层延拓，在下回合开始时获得1点能量；一次性效果，不是永久增益；打出延拓n的卡牌时获得n层。
- **晶化词条**：打出晶化（）n卡牌时，将n张对应晶化加入手牌；括号空白时为普通晶化。
- **晶化牌**：一类衍生状态牌，一般为0费、保留、消耗。每回合手动打出至多1张，自动打出晶化不计入次数；变体可具有额外效果。
- **晶抗**：打出牌并完成基础效果后，若剩余能量不为0，触发对应效果。
- **晶逆**：打出牌并完成基础效果后，若剩余能量为0，触发对应效果。
- **卡牌特例**：量子点使每回合前2张牌同时触发晶抗和晶逆效果。

## 待确认的规则

- 宏枝晶缺少效果。
- 一张1费普通技能缺少名称：消耗1张牌，下个回合开始时将其打出，升级获得保留。
- 崩碎之歌未升级的伤害计数口径。
- 晶化数量未明确时，统计手牌还是所有牌堆。
- 重放1和重放2的次数定义，以及晶抗/晶逆的重放触发规则。
- 手中光环的叠加与离手移除规则，以及晶化-Pb的回合结束顺序。
- 下一回合开始时打出的牌与延拓结算的先后顺序。
- 初始卡组各卡数量，以及晶币的永久递减下限和跨存档持续方式。

## 实现安排

先实现延拓结算、晶化生成和晶化打出限制，之后实现普通与具名晶化效果。晶抗和晶逆在基础效果完成后统一判定；各卡调用统一机制。

优先验证简单伤害、格挡和资源生成卡，再验证跨回合、自动打出、手中光环、变化和永久数值的卡牌。

## 机制实现解释和验收场景

结算顺序已确认：支付费用 → 基础效果 → 读取剩余能量 → 选择晶抗或晶逆 → 分支效果。量子点按卡牌文本覆盖通常的分支选择。

以下为实现解释：

- 所有晶化变体共享玩家每回合的一次手动额度；自动打出不消耗额度，也不因手动额度已用完而被阻止。
- 晶抗和晶逆在基础效果完成后、同次判定中读取一次能量；例如构象打击的晶抗扣除1能量后，不在同次判定中追加晶逆。
- 量子点按卡牌文本覆盖通常的分支选择。

| 场景 | 预期结果 |
| --- | --- |
| 基础效果结束后剩余能量为1 | 晶抗生效 |
| 基础效果结束后剩余能量为0 | 晶逆生效 |
| 扣费后剩0能量，基础效果获得1能量 | 晶抗生效 |
| 扣费后剩1能量，基础效果失去1能量 | 晶逆生效 |
| 量子点作用于当前卡牌 | 该牌的晶抗、晶逆效果同时触发 |
| 自动打出多张晶化后再手动打出 | 手动额度仍可使用一次 |
| 手动打出一次晶化后再自动打出 | 自动打出仍可进行，手动额度已用完 |
| 下一个玩家回合开始 | 手动晶化额度恢复一次 |
