# 铟星 IndiumStar v0.1.5

修复先古之民事件中的角色兼容缺口。卡牌内容沿用 v0.1.4，仍为 72 张当前设计卡牌（65 张主卡、7 张衍生卡）。

## 修复内容

- 为达弗、涅奥、诺奴佩普、欧洛巴斯、佩尔、坦克斯、特兹卡塔拉、建筑师和瓦库加入中英文占位对话，并补齐回应按钮。对话可重复，避免首次或后续访问时没有角色对话候选。
- 修复达弗的「尘封魔典」在铟星没有先古牌时选择空候选并触发空引用的问题。尚无铟星先古牌时，暂用原版「腐化」作为奖励。
- 奖励回退只作用于铟星，不把腐化加入正常卡池；以后加入可获得的先古牌后，自动沿用原版选择流程。

## 安装

1. 安装前置 [STS2-RitsuLib](https://github.com/BAKAOLC/STS2-RitsuLib)，版本至少为 0.6.2，并遵循前置的安装说明。
2. 完全退出《杀戮尖塔2》，将 `IndiumStar-v0.1.5.zip` 中的 `IndiumStar` 文件夹解压到游戏根目录的 `mods` 文件夹。
3. 更新旧版时完整替换铟星文件，确保 DLL、PCK、清单和本地化均来自本包。文件应直接位于 `mods/IndiumStar/IndiumStar.dll` 等位置，避免重复嵌套外层目录。
4. 在游戏模组菜单启用铟星和 RitsuLib，并按提示重启。

最低游戏版本为 v0.111.0；本版编译和原生验证使用该版本，后续游戏版本尚未验证。安装包不包含前置或游戏程序集。同页提供 `SHA256SUMS.txt`。

## 验证

- Release 编译通过，0 警告、0 错误。
- 使用实际游戏 DLL 复现尘封魔典空候选空引用；安装补丁后，同一设置流程成功得到腐化奖励。
- 确认补丁跳过原版角色，且铟星已有可获得先古牌时不会替换其奖励选择。
- 使用 RitsuLib 0.6.2 和游戏原生对话解析器检查中英文共 18 组对话，访问次数 0、1、2、4、100 均有可选对话，文字、说话者和回应按钮可解析。
- 托管验证注入了本地化和模型缓存，未启动 Godot UI、完整模组加载或真实事件选项交互；实机事件仍待验收。
